# RABT.AI

سوق تقني أردني بواجهة عربية، هوية زيتونية، وضع فاتح وداكن، وباك إند محلي خفيف.

## التشغيل

يتطلب Node.js 20.9 أو أحدث، دون API keys أو قاعدة بيانات خارجية.

```powershell
npm.cmd install
npm.cmd run dev
```

افتح http://localhost:3000. استخدم npm.cmd إذا منعت سياسة PowerShell تشغيل npm.ps1.

```powershell
npm.cmd run build
npm.cmd start
```

## الوظائف والبيانات

- حسابات أفراد ومتاجر بكلمة مرور مشتقة باستخدام scrypt، وجلسات HttpOnly وSameSite.
- دخول مستقل بحساب عرض عربي لاستكشاف الموقع.
- نشر وتعديل وحذف إعلانات مع صورة حتى 1MB والتحقق من ملكية الإعلان على الخادم.
- سلة ومفضلة ومقارنة محفوظة على الخادم ومرتبطة بالحساب بعد الدخول.
- طلبات اهتمام برقم متابعة وصفحة /orders للمشتري. صندوق /account/orders للمتاجر والأفراد يعرض فقط منتجات البائع ومعلومات التواصل مع المشتري وإجمالي حصته من الطلب، مع عدّاد للجديد وتحديد كمقروء. الأسعار وهوية البائع تحسب على الخادم وتبقى محفوظة حتى بعد حذف الإعلان.
- رسائل تواصل محفوظة دون إرسال بريد؛ المراجعة وطلبات الخصوصية يدوية بواسطة المشغل.
- شروط وخصوصية وإرجاع مع مراجع أردنية رسمية. يلزم استكمال بيانات المشغل ومراجعة مختص قبل الإطلاق التجاري.

تُنشأ البيانات تلقائيًا في .data/rabt.json، خارج public ومستثناة من Git. يحفظ الملف الحسابات والجلسات والإعلانات والطلبات والرسائل. لا تحذفه إذا أردت الاحتفاظ بالبيانات، وخذ نسخة احتياطية منه بعد إيقاف الخادم قبل الترقيات.

الحفظ متسلسل داخل عملية Node واحدة، بكتابة ملف مؤقت واستبدال ذري. يناسب localhost أو خادم Node واحد بقرص دائم. استضافة serverless بقرص مؤقت أو تشغيل عدة عمليات يتطلب قاعدة بيانات مشتركة.

الكتالوج والشخصيات المبدئية توضيحية. صور الأجهزة منشأة بالذكاء الاصطناعي ولا توثق الموديلات الفعلية. لا يوجد دفع أو شحن أو دردشة مباشرة أو تحقق بريد أو استعادة كلمة مرور بالبريد. طلبات المنتجات المنشورة من الحسابات تصل إلى صندوق البائع مع معلومات التواصل بعد موافقة المشتري. الطلبات طلبات اهتمام وليست تأكيد شراء. لا توجد لوحة إدارة؛ المشغل يراجع الرسائل من التخزين الخاص.

## الملفات المهمة

- src/app/api/[resource]/route.ts: API الحسابات والإعلانات والتفضيلات والطلبات والتواصل.
- src/lib/server-store.ts: التخزين الخاص.
- src/components/site-extras.tsx: السياسات والتواصل والطلبات والمظهر.
- public/brand-mark.svg وpublic/images/: الهوية والصور.
- BRAND_ASSETS.md: مصدر الأصول ونصوص توليد الصور.

## التحقق

```powershell
npm.cmd run lint
npx.cmd tsc --noEmit
npm.cmd run build
node scripts/check-api.mjs
node scripts/check-incoming-orders.mjs
```

فحص API يحتاج الموقع شغالًا، ويُنشئ بيانات اختبار بعناوين qa-...@example.test. فحص scripts/check-browser.cjs يستخدم Playwright وChrome؛ يمكن تحديد مسار Playwright عبر RABT_PLAYWRIGHT_PATH. لقطات المراجعة في output/review.

## اللغة والترجمة

يتغير اتجاه الصفحة والتواريخ والعملات والنصوص الثابتة والنماذج والتنبيهات والسياسات والمتاجر التجريبية مع اختيار العربية أو الإنجليزية. تُحفظ اللغة بعد التحديث.

النصوص الأساسية في src/i18n/translations.ts، والنصوص الإضافية والسياسات في src/i18n/messages.json، وأسماء ومعلومات بيانات العرض في src/i18n/sample-content.json. لا توجد ترجمة آلية خارجية أو طلبات إلى خدمة ترجمة.

أسماء المتاجر المسجلة تستخدم الاسم العربي أو الإنجليزي المدخل في الحساب. محتوى الأعضاء وأسماء العملاء وبيانات التواصل تبقى كما أدخلها أصحابها إذا لم تتوفر نسخة باللغة الأخرى. تُحفظ نسخة الاسم الإنجليزي للمنتج في الطلبات الجديدة عندما تتوفر.

فحص الترجمة بالمتصفح:

```powershell
node scripts/check-locales.cjs
```

يتطلب Playwright كما في فحص المتصفح، ويفحص الصفحات العامة والحسابات والسلة والمقارنة والطلبات والسياسات والتبديل بين اللغتين والعرض على الموبايل. يحتفظ بتقرير في output/review/locale-audit.json، ويستثني المحتوى الذي أدخله الأعضاء من فحص نصوص الواجهة.
